## 搜索策略

### 第一步：联网搜索
使用 web_search 工具，按以下模板构造搜索词：

```
{区域}租房 {房型} {租型} site:{平台域名}
```

示例：
- `太阳宫租房 两室 整租 site:bj.lianjia.com`
- `太阳宫附近整租一居室 近地铁 2026`
- `北京太阳宫 合租主卧 南向 最新`

**时效性过滤**：搜索时在关键词中加入当前年月（如 `2026`），优先获取近期信息。返回结果中需标注信息来源日期，只采信近 1 个月内的房源。

### 第二步：网页抓取（联网搜索不足时）
使用 web_fetch 工具直接访问平台页面，获取更完整的列表信息。

推荐抓取地址模板：
- 链家太阳宫：`https://bj.lianjia.com/zufang/taiyanggong/`
- 安居客太阳宫：`https://bj.zu.anjuke.com/fangyuan/chaoyang-q-taiyanggong/`
- 58同城太阳宫整租：`https://bj.58.com/taiyanggong/zufang/`
- 豆瓣北京租房小组（最新）：`https://www.douban.com/group/35417/discussion?start=0&type=new`

**豆瓣小组抓取说明**：
- 豆瓣无需登录即可抓取帖子列表，包含标题、发帖人、发帖时间
- 该小组为全北京范围，西坝河/太阳宫等特定区域帖子较少，需从标题关键词筛选
- 抓取后过滤包含目标区域关键词的帖子（如"西坝河"、"太阳宫"、"芍药居"）
- 好房源更新快，建议优先看当天或近 3 天内的帖子
- 若列表页帖子不含目标区域，补充用搜索引擎检索：
  ```
  site:douban.com/group [区域] 租房 合租
  ```
  或直接访问豆瓣搜索：
  `https://www.douban.com/search?cat=1013&q=[区域]+租房`

### 第三步：手动粘贴（前两步失败时）
若平台有反爬限制导致信息获取不完整，提示用户：
> "平台限制了自动获取，请将房源链接或页面内容粘贴给我，我来帮你分析和整理。"

## 搜索关键词模板

### 基础搜索
```
北京[区域]附近[租型][房型]租房[年份]
```

### 带偏好搜索
```
[区域][租型][房型] 南向 近地铁 性价比 [年份]
```

### 价格区间搜索
```
[区域]租房 [最低价]-[最高价]元/月 [房型]
```

## 信息时效判断规则

- ✅ 可信：发布/更新日期在近 30 天内
- ⚠️ 参考：发布日期在 1-3 个月内，需注意价格可能有变化
- ❌ 过期：3 个月以上，仅作市场行情参考，不推荐直接联系
